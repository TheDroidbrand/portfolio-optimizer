# Portfolio Optimizer

A Financial Engineering project that helps investors analyze portfolios, calculate risk and return metrics, generate efficient frontiers, and identify optimal asset allocations.

## Features

- Portfolio return calculation
- Portfolio risk analysis
- Sharpe ratio calculation
- Efficient frontier visualization
- Monte Carlo simulation
- Portfolio optimization

## Tech Stack

### Backend
- Python
- FastAPI
- Pandas
- NumPy
- SciPy

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
